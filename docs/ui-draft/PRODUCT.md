# Gravity UI draft

## Platform

web

This browser prototype evaluates the interface of Gravity's existing Windows and macOS desktop PDF application. It does not replace either native application.

## Users and purpose

People reading PDFs, filling existing forms, and organizing pages. The comparison gives reading and organizing equal priority, as requested.

## Capabilities and constraints

The native app supports reading, search, bookmarks, page organization, undo, saving, and printing. This prototype demonstrates navigation, search within the sample outline, page selection, rotation, duplication, deletion, reordering, and undo. File operations are outside the prototype.

## Brand commitments

Preserve Gravity's name and document-first purpose. The selected direction is the first Lucide redesign, with a Read/Organize switch and Outline/Pages sidebar. It uses Apple Human Interface Guidelines as a reference and Tufte's principles of clear information hierarchy and reduced non-content ornament. A subsequent styling-only comparison remains available as an alternate study; the user selected the first design after viewing both.

## Evidence

The comparison uses the repository's saved reading and organizing screenshots. Document images are crops of that same sample, with provenance recorded in README.md. These references predate the current collapsible Pages panel and are labeled accordingly.

## Accessibility

Target WCAG AAA text contrast, keyboard operation, visible focus, labeled icon buttons, 44-pixel primary controls, reduced motion, and a usable narrow layout. This draft is not a full accessibility conformance assessment.
